jp-law-mcp（試験公開）

ソースコード・使い方: github.com/yabooung/jp-law-mcp（コード Apache-2.0・データ CC BY 4.0）

日本の法令・国会会議録を Claude などの AI から使うための MCP サーバーです。条文の取得（時点指定）、改正履歴・新旧比較、本文検索、法令引用の実在確認、引用・委任の逆引き、国会会議録の発言検索ができます。

MCP の接続先（Streamable HTTP）: https://jp-law-mcp.vercel.app/mcp

出典: e-Gov 法令検索（デジタル庁）、国会会議録検索システム（国立国会図書館）、JLaw-CiteGraph。結果は確認の手がかりです。正確な内容は各原文リンクで確かめてください。外部 API への負担を抑えるため、1 分あたりの回数に上限があります。
